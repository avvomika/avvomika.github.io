# Avvomika — The Sims 4, inZOI и The Sims 3

Новая структура бокового меню:

- **The Sims 4** (символ ♢): Обзор; Мир → Династия Sims Stories, Двадцатка влиятельных семей, Семьи Sims Stories, Персонажи, Города; Сверхъестественное; Архив.
- **inZOI**: отдельная редактируемая страница, можно добавлять тексты и вложенные страницы.
- **The Sims 3**: отдельная редактируемая страница, можно добавлять тексты и вложенные страницы.
- **Об авторе** — отдельно от игр.

Данные и идентификаторы старых страниц Sims Stories сохранены. Для переноса пользовательского наполнения используйте «Экспорт JSON» в прежней версии → «Импорт JSON» в новой. После импорта новое меню и новые разделы будут восстановлены автоматически.

## Локальный просмотр

Распакуйте архив и откройте `index.html`. Редактор сохраняет черновик в браузере. Не забывайте делать «Экспорт JSON».

## GitHub Pages

Для размещения на GitHub Pages загрузите все файлы в корень публичного репозитория. Опубликованная версия загружает материалы из `data.json`. Для обновления опубликованных материалов экспортируйте JSON из редактора и замените `data.json` в репозитории.

Важно: `?edit=1` — локальный режим редактора, а не пароль. Пользователи без доступа к репозиторию не могут менять сайт для остальных.


## Фото и ссылки — версия редактора

1. Открой нужную страницу: например, The Sims 4 → Мир → Двадцатка → семья Гот.
2. Нажми «＋ Добавить на страницу» → «Текстовый раздел».
3. Для фото нажми «Фотография с компьютера» и выбери JPG/PNG/WebP. Редактор уменьшит изображение перед сохранением. Можно также указать ссылку на фото, опубликованное в интернете, или относительный путь из папки сайта, например `images/goth.jpg`.
4. Чтобы сделать кнопку, вставь адрес древа в «Внешняя ссылка», а в «Текст ссылки» напиши `Древо семьи Гот` или `Семейное древо`.
5. Чтобы вставить именованную ссылку **внутри текста** биографии, используй `[Древо семьи Гот](https://адрес_нужного_древа)` — на сайте отобразится только подпись.
6. После редактирования обязательно нажми «Редактор» → «Экспорт JSON» и сохрани резервную копию. При публикации загрузи `data.json` в GitHub вместе с файлом сайта.

**Примечание о фотографиях.** Фото, выбранные в редакторе, хранятся в JSON в кодированном виде. Для первых небольших статей это удобно, но если фотографий станет много, лучше сохранять их отдельными файлами в папке `images/` репозитория. Размер хранилища браузера ограничен.

- Как всегда, перед сменой версии нужно экспортировать свой `data.json`; новая версия поддерживает старый JSON.


## Одна общая кнопка экспорта

В самом низу бокового меню есть кнопка **«↓ Экспортировать всё»**.
Сначала добавьте или отредактируйте любое количество страниц: династии, дома, семейства, персонажей, фото и ссылки на древа. Нажмите «Сохранить» в каждой форме.
После окончания нажмите кнопку экспорта **один раз**: браузер скачает **data.json**, содержащий весь текущий набор данных сайта, а не только активную страницу.
Сохраните копию этого файла. Чтобы изменения появились на публичном сайте GitHub Pages, замените **data.json** в корне репозитория на экспортированный и сделайте commit. Сам по себе экспорт **не публикует** изменения.

**Если вы уже заполняли предыдущую версию:** прежде чем работать в новой, используйте старый экспортированный JSON: откройте «Редактор» → «Импорт JSON», выберите файл, после загрузки проверьте, что все ваши страницы на месте. Затем редактируйте дальше.

Фотографии, которые добавлялись в виде встроенных данных, могут сильно увеличить размер data.json; при большой библиотеке фотографий их впоследствии стоит вынести в отдельную папку сайта.
